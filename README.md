# Sphinx Launcher

**Sphinx Launcher** — лаунчер для игры на Minecraft-подобных сборках. Быстрый, лёгкий и настраиваемый. Сделан на **Next.js** (интерфейс) и **Rust + Tauri** (оболочка), поэтому весит совсем немного и не тянет за собой браузер.

> v0.1.0 — ранняя версия. Часть функций ещё в разработке и помечена как `dev`.

---

## Возможности

- 🎮 **Играть** — запуск сборки в один клик
- 🎨 **Настройки**
  - **Оформление** — акцентный цвет, цвет кнопок и выделения (выбор сохраняется)
  - **Игра** — указание пути к Java, выбор версии для автоскачивания
- 🌐 **Дискорд-статус** — лаунчер показывает в Discord, что вы «В лаунчере»
- 🔒 Безопасный и приватный — не собирает и не отправляет никаких данных

---

## Системные требования

- **Windows 10 / 11** (64-бит)
- **WebView2** (обычно уже установлен; если нет — предложит скачать)
- ~100 МБ свободного места

## Установка

1. Скачайте установщик `Sphinx Launcher_0.1.0_x64-setup.exe`.
2. Запустите его и нажмите «Установить».
3. Готово — запускайте лаунчер с рабочего стола или из меню «Пуск».

Альтернативный способ — MSI-установщик `Sphinx Launcher_0.1.0_x64_en-US.msi` (подходит для корпоративных установок через групповые политики).

---

## Быстрый старт

1. **Выберите Java** (вкладка «Настройки» → «Игра»):
   - **Указать путь** — покажет, где у вас стоит Java (`java.exe`).
   - **Авто** — лаунчер сам скачает нужную версию (в разработке).
2. **Скачайте Java**, если её нет: выберите версию (8–25) и нажмите **«Скачать»**. Берётся сборка Eclipse Temurin с проверкой контрольной суммы.
3. Настройте **оформление** под себя — акцент и цвет кнопок.
4. Возвращайтесь на главный экран и жмите **Играть**.

> Настройки сохраняются автоматически — при следующем запуске всё останется как вы выбрали.

## Сборка из исходников

### Необходимые инструменты

| Инструмент | Зачем | Как проверить |
| --- | --- | --- |
| **Node.js** (18+) | сборка интерфейса | `node --version` |
| **Rust** (stable) | сборка оболочки | `rustc --version` |
| **WebView2** | работа окна | ставится автоматически |

### Шаги

```bash
# 1. Установить зависимости интерфейса
npm install

# 2. Собрать установщик (MSI + EXE)
npm run tauri build
```

Готовые установщики появятся здесь:

```
src-tauri/target/release/bundle/msi/Sphinx Launcher_0.1.0_x64_en-US.msi
src-tauri/target/release/bundle/nsis/Sphinx Launcher_0.1.0_x64-setup.exe
```

### Режим разработки

```bash
npm install
npm run tauri dev
```

Окно с автоперезагрузкой откроется сразу. Правки интерфейса применяются на лету, код на Rust — после пересборки.

### Полезные команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | запустить только интерфейс (Next.js) в браузере |
| `npm run build` | собрать статический фронтенд (папка `out/`) |
| `npm run tauri dev` | запустить приложение в режиме разработки |
| `npm run tauri build` | собрать релизные установщики |
| `npm run tauri build --debug --no-bundle` | быстрая отладочная сборка без установщика |

## Частые вопросы

**Почему окно нельзя свернуть через таскбар?**
У лаунчера нет стандартной рамки — используйте три цветные точки справа сверху: закрыть / свернуть / развернуть.

**Приложение пишет, что не нашло Java. Что делать?**
В «Настройках» → «Игра» укажите путь к `java.exe` вручную или дождитесь автоматической загрузки.

**Можно ли ставить кастомные темы?**
Сейчас доступен выбор акцентного цвета и цвета кнопок. Тёмная / светлая / системная темы — в разработке (`dev`).
